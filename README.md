# Dsimpson Studio

一个设计师的公开工作台。

这里放的不是灵感收藏，是**正在执行的一件事**：用 3D 打印做一盏灯，在小红书上卖出去。

仓库存在的理由：让 AI 随时能读到完整背景——我是谁、卡在哪、下一步做什么——然后接着往下帮。

## 怎么让 AI 用

**方式一（推荐）**：把仓库地址发给 AI，让它先读 `AGENTS.md`，再按需读其他文件。

**方式二**：本地 clone 后，让 AI 直接读目录：

```bash
git clone https://github.com/Dsimpson-man/dsimpson-studio.git
```

**方式三**：只贴 `AGENTS.md` 给 AI，也能拿到 80% 的上下文。

每次开始新的对话，先读 `AGENTS.md` 和 `进度.md`——前者给背景，后者给现状。两者加起来就够了。
